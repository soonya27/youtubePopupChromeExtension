# YT Pop Out (Soso)

유튜브 영상을 항상 위에 떠 있는 팝아웃(PiP) 창으로 꺼내 보는 크롬 확장 프로그램입니다.
다른 탭이나 앱에서 작업하면서 영상을 계속 볼 수 있습니다.

## 주요 기능

- 유튜브 플레이어 컨트롤 바에 팝아웃 버튼 추가
- 팝아웃 창 안에서 재생/일시정지, 10초 이동, 탐색, 음소거 조작
- 팝아웃을 닫으면 영상이 원래 탭의 플레이어로 돌아가고, 재생 상태 유지
- 유튜브가 아닌 사이트의 `<video>`도 확장 아이콘을 눌러 팝아웃 가능

## 설치

크롬 웹 스토어에 등록되어 있지 않아 직접 불러와야 합니다.

1. 이 저장소를 내려받습니다. `yt-pip-popout.zip`을 쓴다면 압축을 풉니다. (압축을 풀면 폴더 이름은 `yt-popout`이고, 내용은 `yt-pip-popout` 폴더와 같습니다.)
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.

설치 전에 열어 둔 유튜브 탭은 새로고침해야 플레이어에 버튼이 나타납니다.

## 사용법

팝아웃을 여는 방법은 세 가지입니다. 같은 동작을 한 번 더 하면 닫힙니다.

| 방법 | 동작 범위 |
| --- | --- |
| 유튜브 플레이어 오른쪽 아래의 팝아웃 버튼 | 유튜브 |
| 툴바의 확장 아이콘 | 현재 탭 (`<video>`가 있는 사이트) |
| 단축키 `Alt+P` (Mac은 `Option+P`) | 현재 탭 (`<video>`가 있는 사이트) |

유튜브에서는 **플레이어 안의 버튼을 쓰는 것이 가장 안정적입니다.** 아이콘이나 단축키로 열리지 않으면 플레이어 버튼을 눌러 주세요.

단축키는 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다.

### 팝아웃 창 조작

컨트롤 바는 마우스를 움직일 때 나타나고 2초 뒤 사라집니다. 일시정지 중에는 계속 보입니다.

| 조작 | 키보드 | 버튼 |
| --- | --- | --- |
| 재생/일시정지 | `Space`, `K` | `▶` / `❚❚`, 또는 영상 클릭 |
| 뒤로 이동 | `←` (5초) | `⟲` (10초) |
| 앞으로 이동 | `→` (5초) | `⟳` (10초) |
| 음소거 | `M` | `🔊` / `🔇` |
| 탭으로 되돌리기 | `Esc` | `⤓` |

## 동작 방식

- **Document Picture-in-Picture**(Chrome 116 이상)를 우선 사용합니다. `<video>` 요소 자체를 팝아웃 창으로 옮기기 때문에 유튜브 플레이어가 같은 영상을 계속 제어합니다.
- Document PiP를 쓸 수 없으면 브라우저 **기본 PiP**로 전환합니다. 이 경우 커스텀 컨트롤은 표시되지 않습니다.
- 유튜브의 Trusted Types CSP 때문에 UI는 `innerHTML` 없이 DOM API로만 만듭니다.

## 권한

| 권한 | 용도 |
| --- | --- |
| `scripting` | 아이콘/단축키 사용 시 현재 탭에 스크립트 실행 |
| `activeTab` | 유튜브가 아닌 사이트에서도 사용자가 실행한 탭에 한해 접근 |
| `*://*.youtube.com/*` | 유튜브 페이지에 플레이어 버튼 삽입 |

## 제한 사항

- `chrome://` 페이지처럼 스크립트를 넣을 수 없는 페이지에서는 동작하지 않습니다.
- 유튜브 외 사이트에는 플레이어 버튼이 없어서, 아이콘이나 단축키로 열리지 않으면 대체 수단이 없습니다.
- 유튜브 화면 구조가 바뀌면 플레이어 버튼이 나타나지 않을 수 있습니다. 버튼은 `#movie_player .ytp-right-controls`에 삽입됩니다.

## 파일 구성

```
yt-pip-popout/
├── manifest.json   확장 설정 (Manifest V3)
├── background.js   아이콘/단축키 처리, 현재 탭에 스크립트 주입
└── content.js      영상 탐색, 팝아웃 창과 컨트롤, 플레이어 버튼 삽입
yt-pip-popout.zip   배포용 압축 파일
```
